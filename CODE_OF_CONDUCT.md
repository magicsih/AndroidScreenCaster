# Code of Conduct

Help make this project welcoming and useful for people with different backgrounds, skill levels, and viewpoints.

- Be respectful. Explain disagreements with evidence and address the work rather than the person.
- Give constructive feedback and credit others' contributions.
- Respect privacy. Do not publish private information, credentials, or screenshots without permission.
- Do not harass, threaten, discriminate, spam, or make unwanted sexual comments or advances.

These expectations apply to Issues, pull requests, Discussions, and other project spaces. Maintainers may edit or remove inappropriate contributions and limit participation when needed. They should explain the reason and apply the same expectations to themselves.

To report unacceptable behavior privately, contact the maintainer through the contact information on [magicsih's GitHub profile](https://github.com/magicsih). Do not publish identifying details of a report in a public issue. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
